# TheTom Homebrew Tap

Custom Homebrew formulae.

## Install

```bash
brew tap TheTom/tap
```

## Formulae

| Formula | Description |
|---------|-------------|
| `vllm-swift` | Native Swift/Metal backend for vLLM on Apple Silicon |

## Usage

```bash
brew install TheTom/tap/vllm-swift
```

Or after tapping:

```bash
brew install vllm-swift
```
